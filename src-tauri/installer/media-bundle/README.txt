This directory is populated in the Windows CI build from the pinned, SHA-256-verified FFmpeg 9.0.2 essentials archive.
The Windows build MUST stage ffmpeg.exe, ffprobe.exe, LICENSE, and SOURCE.txt here before Tauri packaging.
The placeholder is intentionally not a runnable media engine. Never ship it as a substitute.
The FFmpeg binaries are distributed under GPLv3; see https://www.gyan.dev/ffmpeg/builds/ and https://ffmpeg.org/legal.html.
