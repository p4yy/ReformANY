## [1.0.0] — planned, not published

The following describe the current Windows release candidate; **v1.0.0 has not been tagged or released**.

### Features

- ReformANY Windows workspaces for supported image, media, archive, document and spreadsheet conversions.
- File Explorer Orbit quick actions; PDF page arrangement, preview, extraction, watermarking and visual signing.
- Optional local media engines and a separate portable executable without the setup wizard.

### Verification and limits

- Automated source checks and Windows UI smoke tests are available on the development pull request.
- A 269-page Arrange PDF regression test exercises real mouse-wheel, track-click and scrollbar-thumb scrolling.
- Remaining release gates are tracked in [RELEASE_CHECKLIST.md](docs/RELEASE_CHECKLIST.md), including dependency advisories, license confirmation and manual visual QA.
