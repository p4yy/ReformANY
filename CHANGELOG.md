## [v0.3.0] — 2026-11-11
First official Windows release of ReformANY.

- Windows workspace for supported image, PDF, media, document, data and archive tasks.
- **ReformANY Orbit** file/folder shortcuts and HoveR preview.
- Portable `ReformANY-Portable.exe` and premium `reformany-setup.exe` setup wizard.
- Bundled offline FFmpeg/FFprobe in the published EXEs.
- Passing automated Windows build, Orbit, installer, native Rust and offline-media tests.
- SHA-256 release checksums and Acev Dev Co proprietary source-available license.

**Limits:** Conversions are route-specific, and some require locally installed external programs. Release binaries are unsigned; SmartScreen may warn. See [format support](docs/FORMAT_SUPPORT.md) and [security](SECURITY.md).
