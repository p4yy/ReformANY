# Contributing to ReformANY

Thanks for taking the time to improve ReformANY. The project is publicly viewable but is **not open source**. Its first-party code and artwork are covered by the proprietary [LICENSE](LICENSE); publishing the source does not grant a general right to distribute modified builds.

## Before making changes

- Search the [existing issues](https://github.com/p4yy/ReformANY/issues) and pull requests to avoid duplicate work.
- Open an issue describing the problem, supported operating system and a minimal reproduction, or explain your proposed feature and how it will be tested.
- Request written permission from the maintainer before submitting code or artwork that modifies proprietary ReformANY material. Additional contribution terms may be required; opening a pull request alone does not change the license.
- Report vulnerabilities privately as described in [SECURITY.md](SECURITY.md).

## Standards for approved pull requests

Keep the change focused, describe expected behavior, add tests where possible, and retain the original files for comparison. Do not remove license notices or introduce telemetry/network uploads. For UI changes, use privacy-reviewed captures from synthetic Windows test fixtures only; never include images or videos from private chats. Verify actual keyboard, wheel and pointer interactions rather than appearance alone.

Development commands are in the [README](README.md). Include a clear test plan and explain any remaining manual Windows checks. Maintainers may close proposals that do not fit the current roadmap.
