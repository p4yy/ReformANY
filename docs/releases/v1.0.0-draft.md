# ReformANY v1.0.0 — draft release notes

**Not published.** Finalize this document only after the release checklist passes and v1.0.0 is tagged from the reviewed `main` commit.

## Highlights

ReformANY brings commonly used Windows file conversions and document actions into one local application. A file can be opened in the main workspace or through the compact Orbit shortcut in File Explorer.

## Features

- Convert supported images with size, orientation and output-format controls.
- Work with local PDFs: preview, reorder/extract pages, apply a watermark, add a visual signature and save protected copies.
- Convert or process supported audio and video with FFmpeg, and work with ZIP archives, selected e-books, subtitles and spreadsheets.
- Use ReformANY Orbit for quick source-aware actions from File Explorer.
- Choose a regular installer or the separate portable application. Both are intended for Windows; requirements differ.

## Installation

**Portable:** Download `ReformANY-v1.0.0-windows-portable.zip` and `SHA256SUMS.txt` from the official release page once published. Check its SHA-256, extract the archive and run `ReformANY.exe`. Windows WebView2 must be available. The portable application does not use the setup wizard.

**Installer:** If a verified installer is attached to the final release, download it separately and follow its setup steps. Do not confuse the installer with the portable ZIP.

## Known limits and cautions

- Format support is route-specific, not a promise of conversion between arbitrary file types; see [the format matrix](../FORMAT_SUPPORT.md).
- Some document/archive routes require LibreOffice, Calibre, 7-Zip or WinRAR; codec compatibility also varies.
- Windows SmartScreen may warn about unsigned binaries until code signing is established. A checksum is not a signature.
- Output formatting, metadata and color fidelity are not always preserved; inspect important results before discarding source files.
- **Do not publish v1.0.0** while npm audit reports high-severity advisories in `xlsx` and `pdfjs-dist`, or while other [release gates](../RELEASE_CHECKLIST.md) remain open. Changes to the PDF.js parser/worker require full PDF feature regression testing.
