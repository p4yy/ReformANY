## P0 / P2 / P3 / P4 — root causes and changes

| File | Root cause / verified code condition | Intervention |
|---|---|---|
| `src/main.tsx` | Eleven cascading stylesheets share mutable selectors; `window-system.css` loads last | Inspected import order; final shared contract placed in the last stylesheet to avoid fragile per-view offsets |
| `src/styles.css`, `src/product-ui.css`, `src/desktop-polish.css` | Primary button colors overridden by multiple white-on-sage declarations; generic native select padding and low-opacity disabled elements | Last-cascade scoped alignment/contrast normalization |
| `src/window-system.css` | Orbit editor scroll and dialog container geometry conflicts with other styles | Added intrinsic-height form rules, non-overflowing input wrapper, controlled panel scrolling, controls alignment and active-pill foreground |
| `src/orbit-finish.css`, `src/orbit-reference.css` | Several versions of hub/ring geometry apply to same selectors | Anchored hub and center outline as positioned siblings in the `.orbit-disc` coordinate space via final stylesheet |
| `src/Orbit.tsx` | Root `.orbit-frame` pointer-down close guard excluded only dialogs and tabs, **not the native titlebar** | Excluded native titlebar/editor mode from outside-click dismissal; show close failures |
| `src/WindowChrome.tsx` | Tauri minimize/maximize/close methods existed, but close error display path applied only to the default callback | Close now uses the common error-handled native operation wrapper |
| `src/ExtraWorkspaces.tsx` | Mode switch remained active during a job; a completed result could visually appear under a different operation | Prevent mode switching while processing, disable mode tabs and provide exact CTA labels |
| `src/PdfPageDialog.tsx` | Vague page-range wording | Clarified page-range labels and error instructions |
| `src/brand.ts`, existing icon PNG | Current icon embeds a rounded-square background as image pixels; no confirmed transparent circular **green** logo provided | Existing icon retained. CSS surrounding frames removed where possible; **official asset replacement not yet complete** |

**Important:** CSS-level corrections are *source fixes*, not screenshot-verified acceptance. Validate minimum/native/expanded sizes on Windows; high-contrast visual checks and mouse/keyboard interaction across every Orbit editor remain outstanding.
