# Code of conduct

We want discussion about ReformANY to stay useful, respectful and technical.

- Be constructive: critique code and reproducible behavior, not people.
- Avoid harassment, threats, hateful language, personal attacks and deliberately disruptive behavior.
- Keep public reports free of private documents, credentials, unsolicited advertising or security exploit details.
- Respect attribution, software licenses and the confidentiality of responsibly reported vulnerabilities.

Maintainers may edit or remove inappropriate comments, lock discussions or restrict participation where necessary. To raise a conduct concern, contact the project owner through [GitHub](https://github.com/p4yy) without posting personal information publicly. For security issues use [SECURITY.md](SECURITY.md).

This policy covers project-owned GitHub issues, pull requests and discussions. Decisions should be proportionate and consistent.
